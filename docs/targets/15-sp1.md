# Target Dossier：SP1

状态：`draft`
Target ID：`sp1`
成熟度 ceiling（静态 dossier）：`research`
阶段：研究期（ADR-0017）；**无** registry materializer；Plan 设计见
[`../research/26-zkvm-trio-cairo-risc0-sp1-design.md`](../research/26-zkvm-trio-cairo-risc0-sp1-design.md)

## 1. 身份与来源

Succinct **SP1** 证明 RISC-V guest 执行；与 `risc0` / `openvm` 同属 zkVM family，但
prover、SDK、proof 对象与 tool 版本线不同，因此必须有独立 `Sp1Plan` / `Sp1GuestIR`。

官方入口（研究期 plain link）：[SP1 docs](https://docs.succinct.xyz/)（实现前钉版本）。

## 2. 执行、状态、调用、失败与资源

- 执行：SP1 guest（通常 Rust→RISC-V）在锁定 zkVM 配置下执行。
- 状态：guest memory + 显式 I/O；无原生链 persistent storage。
- 调用：guest 内；链上 call/schedule **Q0 FC**。
- 失败：guest trap 与 proof verify 失败分开。
- 资源：cycle/prover 成本进 Plan；与 risc0 **数字不可互换**。

## 3. Portable fragment（Q0）与扩展

与 RPT-026 §3 / `risc0` dossier **同一 Q0 表**（承认面取交集）。SP1 多出来的 precompile/
syscall 只能做 extension，不得放宽 Q0。

## 4. `Sp1Plan` schema（设计冻结）

字段与 `Risc0Plan` **同形**，类型名必须不同：

```text
Sp1Plan {
  profileId                 -- e.g. sp1-guest-u64-v1
  semanticsDigest
  sourceHash, semanticHash
  continuity                -- external-public-pre-post
  proofMode                 -- none | execute-only | prove
  guest {
    entrypoints[] { name, role,
                    publicInputLayout, privateInputLayout, publicOutputLayout }
    memoryLayout
    cycleBudget
  }
  methods[]
  stateSlots[]
  failurePolicy
  sp1ProofBinding           -- VK/proof 对象绑定；Q0 可空
  resourceEnvelope
}
```

**禁止** `abbrev Sp1Plan := Risc0Plan` 或共享 private lowering 入口。

## 5. Target IR 与制品

`Sp1Plan → Sp1GuestIR → 受控 guest → ELF →（可选）SP1 proof 制品`。

首切片 **Z0–Z1**；deployable=false。

## 6. 工具链

冻结 SP1 CLI/crates 单一版本线 + Tool Lock；与 risc0/OpenVM 二进制不得混用。

## 7. 证明 / 结算

同 zkVM 轴：`zkvm-execution` + `external-verifier`。无 PF 产品链部署。

## 8. 安全

与 risc0 同类；另防 SP1/RISC Zero 工具链交叉污染与 proof 格式误标。

## 9. 验证阶梯

Counter Q0 → Plan/IR 金样 → guest build → execute → prove/verify（可选）。

## 10. 不支持与退出

当前不实现。作为 **OpenVM 之后的第二 zkVM 叶候选 B**（与 `risc0` 二选一）。选中实现前须
独立实现 ADR；未选中者保持 research dossier。
